# sample-lessons

A lessons site: Markdown fields where only one allows formulas, pictures kept in storage through file fields, pages that load KaTeX only for a lesson that has a formula, and the admin panel with its visual editor.

It is a sample and is not published.

## Run it

```bash
./gradlew :samples:sample-lessons:run
```

Open `http://localhost:8080` for the lessons and `/admin` to edit them: sign in with the token `demo-editor`.
